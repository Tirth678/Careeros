# CareerOS Frontend

CareerOS is a Smart Student Career Profile platform. This repository contains the React frontend.

## Tech Stack
- React 19
- TypeScript
- Vite
- Tailwind CSS 3
- React Router DOM
- Lucide React

## Getting Started

1. Install dependencies:
\`\`\`bash
npm install
\`\`\`

2. Run the development server:
\`\`\`bash
npm run dev
\`\`\`

The app will start at \`http://localhost:5173\`.

## Features
- **Landing Page:** A beautiful, responsive landing page explaining the platform.
- **Authentication:** Simulated login and signup pages.
- **Dashboard:** Overview of career readiness, streak, skills, and next best actions.
- **Profile:** Manage your academics, projects, and certifications.
- **Skills:** Visualize your strong, developing, and missing skills.
- **Careers & Analysis:** Explore career matches and see detailed skill gap analysis.
- **Roadmap:** Interactive timeline with tasks to improve your readiness.

## Mock Data
This application uses mock data located in \`src/data/\`. 
When the backend is ready, you can replace these files with API calls without changing the UI components!
